# Hospital Management System (C)

A modular console-based **Hospital Management System** developed in **C** for **CSE 1290 (Software Development I)** using Code::Blocks and binary file storage (`.dat`).

## Project Structure

- `structs.h` — Shared data structures, constants, and function declarations.
- `auth_setup.c` — Authentication and initial setup logic.
- `patient_queue.c` — Patient queue and record management.
- `admission_bill.c` — Patient admission and billing module.
- `display_board.c` — Display board logic for status/queue viewing.
- `main.c` — Main entry point and menu navigation.
- `HospitalManagement.cbp` — Code::Blocks project configuration file.
- `.gitignore` — Excludes build artifacts (`*.o`, `*.exe`, `bin/`, `obj/`, etc.) and `.dat` data files.

## How to Run

1. Open `HospitalManagement.cbp` in **Code::Blocks**.
2. Build and run the project (`F9`) to compile all source files and generate the executable.
